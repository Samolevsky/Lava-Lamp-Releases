# Lava Lamp

Create animated 3D sculptures, style materials and lighting, and export PNG, OBJ or animation sequences. [Open the website](https://lava-lamp.samolevsky.com/).

Use **Check for Updates…** in the Lava Lamp menu on macOS or Help on Windows. Download, then restart to install; unsaved changes use Save / Discard / Cancel. macOS apps and installers are Developer ID signed and notarized. Windows packages have cryptographic updater signatures; Windows may warn because they have no Authenticode certificate.

## Moving from Electron

Install and open the [final Electron migration update, 0.1.10](https://github.com/Samolevsky/Lava-Lamp-Releases/releases/tag/v0.1.10), once before installing Tauri. Your license, presets, custom maps and session transfer automatically on the first Tauri launch. Original local data is retained. Existing Tauri test builds can update through Check for Updates.

This repository contains downloads and release notes. The application's source code is private.
