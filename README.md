# Lava Lamp

Lava Lamp is an interactive 3D lava lamp visualizer. Try the [web app](https://lava-lamp.samolevsky.com/).

## Downloads

Open the [latest release](https://github.com/Samolevsky/Lava-Lamp-Releases/releases/latest) and choose:

| Platform | Installer |
| --- | --- |
| macOS Apple Silicon | `Lava-Lamp-<version>-mac-arm64.dmg` |
| macOS Intel | `Lava-Lamp-<version>-mac-intel.dmg` |
| Windows x64 | `Lava-Lamp-<version>-win-x64.exe` |

Windows installers are unsigned. The macOS ZIPs and update metadata are for automatic updates; use a DMG for first installation.

## Updating

In an installed copy, choose **Lava Lamp → Check for Updates…** on macOS or **Help → Check for Updates…** on Windows. Download the update, save your project, then restart when prompted. **Help → Release Notes** opens the release history.

Copies released before automatic updates were introduced need one manual installation of the latest installer.

This repository hosts installers and release notes. The source code is private and is not published here.
